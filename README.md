# Excel Sales and Finance Analytics

## Overview
This project demonstrates end-to-end Sales and Finance analysis using Excel, Power Query, Power Pivot, and DAX. The objective is to transform raw business data into actionable insights for better decision making.

---

## Sales Report

### Objectives
- Build a [Customer Performance Report](https://github.com/farhangulzar-collab/Excel-Sales-Analytics/blob/main/Customer%20Performance%20Report.pdf)
- Compare [Market Performance vs Sales Targets](https://github.com/farhangulzar-collab/Excel-Sales-Analytics/blob/main/Market%20Performance%20vs%20Target%20Report.pdf)

### Business Value
- Monitor customer and market performance  
- Identify sales trends and KPIs  
- Support discount strategy decisions  
- Discover high growth markets  

---

## Finance Report

### Objectives
- P&L by [Fiscal Year](https://github.com/farhangulzar-collab/Excel-Sales-Analytics/blob/main/P%26L%20Statement%20by%20Fiscal%20Year.pdf)
